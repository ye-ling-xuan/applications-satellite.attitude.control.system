# 答辩提纲与提交前核验

## 答辩主线

建议以“单轴与三轴卫星姿态控制：PID 与多种强化学习的公平比较和部署改进”为题，以 [V2 成果入口](../07_单轴三轴多算法对比/README.md) 为当前主线。保留 [V1 技术报告](结项技术报告.md) 与 [三轴 PID 开发演示](../05_三轴拓展演示/README.md)，作为方法迭代和学习过程，避免混用不同版本的执行器条件与统计数字。

1. **问题**：卫星从不同初态转到目标，在力矩有限、惯量有偏差、存在扰动噪声时怎样保持稳定。
2. **建模**：单轴转动方程、三轴欧拉耦合动力学和四元数运动学；解释最短本体系姿态误差、测量噪声、执行器饱和和不同轴数的参数。
3. **方法**：原始/整定/改进 PID、PPO/SAC/TD3，说明经验回放、策略更新和探索的差别。V1 普通与域随机化 PPO 是上一阶段；V2 三种算法采用同一轴下共同训练协议。
4. **公平性**：同一轴下共享仿真器、观测、动作映射、初态、扰动与噪声，验证集选参和选 checkpoint，三个训练种子均保留。相同交互预算不等于相同梯度次数或计算量。
5. **证据**：两轴典型响应、按工况成功率、精度/控制代价和种子波动。完整部署 20 秒，末 5 秒同时满足误差与角速度阈值；失败回合和稳定时间的统计口径都说明。
6. **改进**：先展示 PID 参数整定与额外滤波的分别作用；再展示同一个 RL checkpoint 减去零观测动作的校准前后配对。原模型保留、不重新训练、不读取真实状态；全部改善与退化都报告，原算法排名和部署后处理效果分开。
7. **历史融合**：新增材料有单轴 PPO 和三轴 PPO/SAC/TD3 共 4 份历史策略；统一部署条件下单独复测，不与新等预算、多种子模型混合排名。执行器、时步和积分器变化意味着这是迁移部署复测。
8. **成果与局限**：18 份新模型、原始轨迹、逐回合统计、配对表、图表、报告、原始资产清单；解释刚体仿真与实际系统的差距、持续扰动问题和有限种子/初态样本范围。

具体结论直接引用 V2 入口中生成的融合分析和 CSV。三轴 RL、SAC、TD3 已经实现并训练，不再写为未开展工作；硬件验证、真实能源测量、DDPG 完整实验仍未开展。

## 三分钟演示流程

打开 V2 离线结果页面，说明末 5 秒持续保持判据。展示单轴、三轴各一张同条件结果，再选择一个压力/失败案例。切换原6类控制器与校准后3种 RL，展示同模型、同种子、同环境配置的校准前后变化。最后打开一个 `training_metadata.json` 和校准验证清单，说明实际训练预算、种子与验证选择。已保存页面和图无需现场重新训练。

V1 三轴 PID 开发演示可作备用建模展示，但其执行器上限为每轴 0.2 N·m，V2 三轴比较为每轴 2 N·m，不能把两者曲线当作同条件算法比较。原始材料的早停曲线也不能直接与新持续保持结果比较。

## 每位成员须能解释

- 建模成员：为什么使用四元数，力矩怎样改变角速度，惯量误差怎样影响响应。
- 控制成员：PID 积分饱和与滤波，PPO/SAC/TD3 的观测、动作、奖励、探索与经验回放，训练与推理的区别。
- 改进成员：为什么零观测输出的常量动作可能造成名义残差；校准为什么不等于积分抗扰；校准何时可能损害扰动下的表现；怎样按同 checkpoint、同种子与同配置配对。
- 实验成员：为什么不提前成功终止，失败回合怎样统计；V2 每轴是 20 组初态在 9 工况复用，不是 180 个独立初态，训练种子也不能当成新初态。失败后冻结与填充到 20 秒是计算边界，不表示继续物理演化。
- 报告成员：哪些结论有数据支持，哪些只是解释或猜想；V1、V2 和历史迁移复测如何区分；怎样复现、核对哈希与追溯来源。

## 提交前核验

| 工作标题 | 团队需要完成的动作 |
|---|---|
| 学校要求核对 | 核对原立项承诺、结项模板、截止时间、篇幅、附件及优秀评审规则 |
| 独立复现 | 至少一名未编写主线代码的成员按 V2 README 运行 `run_multi.py check`，评估、绘图与报告均另存到团队复现目录；V1 仍可独立运行 |
| 学习综述 | 根据原始立项要求完善两篇学习综述，逐条核实文献；技术报告不自动代替综述 |
| 分工记录 | 如实记录成员学习与实施工作，不把自动生成部分全部写成成员手工研究 |
| 结论校核 | 每个百分比可追溯到对应版本 CSV；原算法表与校准表独立，统计同种子配对的挽回/失去成功回合；失败与局限保留，不能只挑最佳曲线 |
| 模型与材料保全 | 核对旧原文件及新增目录来源快照、两批副本 SHA256；校准版本复用原 checkpoint，不伪称新增训练模型 |
| 统计范围 | 区分工况配置、独立初态、训练种子和回合数；SD 是种子间波动，不能称作独立任务的置信区间 |
| 提交格式 | 将Markdown内容整理成学校要求的报告和答辩PPT，补团队信息与签字 |
| 演示备份 | 保存结果图与备用录屏；确认本机解释器能加载模型 |

本成果包补齐技术实现、训练与实验基础。学校材料的签字、成员陈述、正式综述和答辩必须由团队核实后完成。
