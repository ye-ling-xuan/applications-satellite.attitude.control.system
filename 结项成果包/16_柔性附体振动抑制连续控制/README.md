# 柔性附体振动抑制连续控制

这是新增的连续力矩控制研究：本体转向时必须同时让柔性附体停止振动。它保留PID、ZVD输入整形加PID、LQR三个传统对照，学习模块使用TD3或SAC每拍输出力矩补偿。不会用简单的转动方向选择替代连续控制问题。

先读[先看结论](先看结论.md)，再打开[最终报告](07_训练修正与复核/08_最终报告/研究报告.html)。原始[研究预声明](研究预声明.md)、[训练修正预声明](07_训练修正与复核/修正预声明.md)与[补充传统对照预声明](07_训练修正与复核/补充对照预声明.md)均保留。

上一级`代码`、`03_学习训练`是未成功的第一次开发，已在独立测试前中止；详情见[中止说明](开发尝试1中止说明.md)。最终可复核研究在`07_训练修正与复核`，该子目录内的`代码`才是正式模型对应的冻结源码。使用已经具备依赖的Python环境：

```powershell
cd .\07_训练修正与复核\代码
& 'D:\Anaconda2024.06-1\python.exe' -X utf8 -B -m pytest test_flexible.py -q
& 'D:\Anaconda2024.06-1\python.exe' -X utf8 -B flexible_study.py verify
```

生产脚本支持`design`、`development`、`formal`、`test`、`verify`。在`07_训练修正与复核`内运行`补充传统控制优化.py`可复现扩展的传统参数搜索；`补充测试与最终报告.py all`生成补充测试及最终36项同时比较的报告。所有输入和选择记录已随包保存。`08_最终报告/最终结果.json`可用于程序汇总，完整配对区间另存于同目录。

本体和附体的模型是低阶仿真近似，不是有限元或实物卫星；力矩平方积分不是实测电能。
