# 执行器约束下的连续姿态跟踪

先打开 [研究报告.html](06_研究报告/研究报告.html)。

本研究已完成实际训练、冻结独立测试、全量回放核验和图表整理。不是静态方向选择任务：AI每0.1秒输出连续力矩补偿，卫星连续跟随30秒扫描指令，执行器同时受力矩幅值和力矩变化速率限制。

结果：PPO组合控制明显优于本次普通PID，但绝大部分改进来自模型前馈和指令预览。相对同一前馈PID基底，三个正式种子的平均RMS误差降低6.59%、3.48%、2.62%，较保守的同时置信区间均跨0，且力矩平方积分和综合均方目标更高。因此未证明学习模块带来可重复、明确的额外优势。

训练共6次、2,359,296个实际环境交互步：两次原开发各131072步，一次追加开发和三次正式训练各524288步。正式种子111、222、333的模型分别由验证集选定327680、32768、32768步检查点，均大于0。后期模型常比早期检查点差，不能用累计步数代表效果持续提高。

测试共1024个控制器回合、307200个物理区间。这里包含两份0步回退的开发诊断，其输出严格等于同一前馈PID，不能算作两种成功的AI方法。每个控制器使用相同128条独立参考轨迹。全量核验通过；独立ODE检查代表区间通过，不能等同于真实硬件验证。

MPC采用同一固定3秒时域凸二次规划的SLSQP解，38400次调用均报告成功，约束残差最大2.07e-11；仍有10/128轨迹出现物理失败。这说明有限时域/权重/终端设计不足，不能把该实现当作MPC方法的能力上限，也不能据此宣称强化学习优于充分优化的MPC。

本研究的惯量、力矩和速率限制是仿真示例，没有以具体型号反作用飞轮的实测数据校准。实际力矩视为可测量反馈，所有方法均可使用。结论限于单轴，未进行三轴联合训练。
