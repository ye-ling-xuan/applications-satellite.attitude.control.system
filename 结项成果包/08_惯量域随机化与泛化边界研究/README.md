主要结论：仅惯量随机化未扩大本次可用范围。三轴标称训练SAC域外成功率100%，随机化组84.4%；共同经验范围由覆盖已测0.5–1.5变为0.5–1.1。两轴充分整定PID均覆盖已测范围。校准标称训练SAC的力矩平方积分较低，但响应较慢，全程RMS较大。完整数据包含所有种子和失败回合。

“免重整定”指跨固定惯量回合冻结权重、增益与偏置，不是在线辨识或自适应。经验区间只对应离散网格、30初态与20秒离散判据，未找到覆盖整个已测网格的控制器的真实边界。
