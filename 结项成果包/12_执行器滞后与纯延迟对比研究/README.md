# 执行器滞后与纯延迟对比研究

本研究已完成。先读[研究结果说明](06_结果与说明/研究结果说明.md)，或打开[结果总览](06_结果与说明/结果总览.html)。实验条件与预定门槛见[研究计划](研究计划.md)。

实际完成8次开发训练、6次正式训练，共420万交互步；12个控制器条目共29,184回合独立测试。全部114个响应分片、12,840,960个采样区间记录（含失败后的填充记录）通过独立核验。256个独立初态在不同参数和控制器间复用。

本轮未获得满足预定可靠性要求的SAC代价优势。直接SAC未通过开发门槛，仅保留诊断测试；一阶滞后中PID加SAC的三个种子虽全部完成范围内测试，但代价高于PID；纯延迟中的正式种子还存在停稳失败。具体奖励设计限制见[奖励诊断](05_独立核验/奖励设计诊断.md)。

计划将一阶滞后和纯延迟分开研究，先完成单轴，对比重新整定PID、传统模型补偿、直接SAC和PID加SAC残差补偿。模型、参数范围、验收条件、开发门槛、预算和预期交付均在计划中列明。

原有结项材料、答辩讲解包和历次研究结果保持原样。

训练采用不同进程并行运行预定种子。延迟顺序调度器遇到另一进程正在运行的202种子时按保护规则退出，未覆盖该次训练；各种子随后均完成500,000步。`03_正式训练完成状态复核.log`记录最终调度检查成功，最终冻结与核验也已通过。
