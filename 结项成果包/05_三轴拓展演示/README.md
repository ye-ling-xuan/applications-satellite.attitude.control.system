# 工作五：三轴四元数姿态 PID 拓展演示

本目录是 **V1 的三轴 PID 开发演示**，将原 week5 的三轴建模工作整理为可重复运行的独立演示。它展示三轴刚体耦合动力学、四元数姿态、带角速度阻尼的 PID、积分限幅与条件积分抗饱和、执行器饱和/死区、扰动和测量噪声。后续新增材料已融合为 **V2 单轴与三轴 PID/PPO/SAC/TD3 同条件实验**，见 [多算法成果入口](../07_单轴三轴多算法对比/README.md)；三轴 RL 不再是未开展任务。

本目录保留原演示代码、场景与产出，不承担多算法排名。V1 演示每轴力矩上限 0.2 N·m，V2 三轴算法比较每轴为 2 N·m；两个版本的曲线和控制代价不能直接当作同条件结果拼接。V2 还保留同 checkpoint 的零动作校准和历史模型独立迁移部署复测，最终统计请按其入口核对。

## 运行与查看结果

依赖 Python、NumPy、Matplotlib。从项目根目录运行：

```powershell
python "结项成果包/05_三轴拓展演示/run_three_axis.py" --check
```

默认输出位于 `outputs`：

| 文件 | 用途 |
|---|---|
| `3axis_response.png` | 姿态、角速度、控制力矩和姿态误差四联图 |
| `trace.csv` | 1001 个时间点的四元数、欧拉角、角速度、命令、实际力矩、扰动与积分状态 |
| `metrics.json` | 模型与控制器配置、判据、稳定时间和误差等实际测量值 |
| `regression_checks.json` | 四元数正负等价、180°符号等价、零误差静止、复位、限幅等验证结果 |
| `pid_calibration.json` | 固定开发工况下 14 组 PID 候选参数比较记录 |

CSV 中每行首先记录该时刻状态，力矩对应从该时刻到下一时刻的保持输入。最后一行没有后续区间，`interval_starts_here=0`，最后一行的力矩零值不代表仿真末段力矩突然归零。所有内部计算使用弧度和 N·m，展示角度使用度。

## 场景与判据

初始欧拉角为 `(30, -20, 45)°`，初始角速度 `(2, -1, 1.5)°/s`，惯量 `(1.2, 1.0, 0.8) kg·m²`。每轴执行器上限 `0.2 N·m`，死区 `0.0005 N·m`。外部扰动由常值偏置、正弦分量和第 8—10 秒的力矩脉冲组成；姿态噪声标准差 `0.1°`，角速度噪声标准差 `0.02°/s`。固定随机种子为 `20261009`，仿真 20 秒，步长 0.02 秒。

成功判据为：最后 5 秒内，每个采样点的真实姿态测地误差均不超过 1°，角速度向量模长均不超过 0.5°/s。稳定时间要求从该时刻起到仿真结束持续达标，且至少保持 5 秒。控制代价是三轴力矩平方之和的时间积分；它没有直接等同于实际执行器能耗。

四元数采用标量在前 `(w,x,y,z)`，表示机体系到惯性系旋转，运动学为 `q̇=0.5 q⊗(0,ω)`。相应机体系误差为 `conj(q_current)⊗q_target` 的最短旋转向量；`q` 和 `-q` 对应相同控制。动力学采用 RK4，并在每步归一化四元数。

## 参数校准与适用范围

原演示积分增益 `(0.10,0.08,0.06)` 在该场景下最后 5 秒最大误差为 1.152°，未达标。保持工况、随机种子和成功阈值不变，比较了 14 组参数后，将积分增益改为 `(0.025,0.020,0.015)`，比例和阻尼增益保持 `(1.8,1.5,1.2)`、`(3.1,2.6,2.1)`。可通过以下命令重建全部候选记录：

```powershell
python "结项成果包/05_三轴拓展演示/calibrate_pid.py"
```

此次实际运行满足上述判据：稳定时间 13.12 秒，最终姿态误差 0.232°，最后 5 秒最大姿态误差 0.321°、最大角速度模长 0.205°/s。全部回归检查通过，四元数最大模长误差为 `2.22e-16`，实际力矩和积分状态均保持在设定上限内。

这是在公开的单一开发场景上校准和展示实现的结果。它不构成三轴鲁棒性统计结论，不应据此声称任意姿态、惯量或扰动下均达标。最终数据请查看 `outputs/metrics.json`。

三轴多工况、多训练种子的 PPO/SAC/TD3 比较与同模型校准结果位于 V2；本开发演示的参数校准记录不能代替 V2 验证集选择或正式测试。建模和结项答辩时可分别使用本目录展示实现过程、V2 展示统一条件下的比较证据。
