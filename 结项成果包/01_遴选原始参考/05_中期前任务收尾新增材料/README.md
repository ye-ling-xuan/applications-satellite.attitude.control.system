## 06 本次分析发现与融合原则

1. 原单轴、三轴环境均在一个时间点达到误差和角速度阈值后成功终止；短轨迹不能证明此后持续保持姿态。新比较应固定完整仿真时长，要求最后一段时间同时保持误差、角速度阈值。
2. 原 `metrics.settling_time` 允许最后一个样本进入阈值即算稳定，没有最小保持时长；`steady_state_error` 采用各控制器不同的入阈后窗口，且失败用 NaN。新比较应在固定末段窗口统计所有成功与失败回合。
3. 原三轴 PID 使用固定 Kp=3、Ki=0.5、Kd=1 及误差有限差分。保留它作为“原始 PID”，同时增加仅用验证集整定的 PID，才能判断改进来自哪一项工作。
4. 原 SAC 续训脚本会在已有步数基础上再增加 80 万步；三个模型实际训练步数及种子需读取 ZIP 元数据核对。“脚本写 80 万步”不等于“全部实际训练同预算”。
5. 原三轴环境存在角速度硬限幅，声明的观测范围与该限幅并不完全一致。新评估应检查模型边界，并明确历史模型部署条件与新模型训练条件。
6. 历史模型复测单独输出，不与新训练的等预算、多种子模型混合排名；最终优势以实际重测为准，不沿用历史图表中的结论。
