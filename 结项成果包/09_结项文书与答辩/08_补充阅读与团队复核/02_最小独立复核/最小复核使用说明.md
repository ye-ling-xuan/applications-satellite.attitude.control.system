# 两个固定场景的最小复核

这份工具供项目成员亲自运行，检查冻结模型、保存轨迹和结项指标是否互相对应。它使用既有V3证据，没有训练新模型、寻找新场景或改变正式统计。附带的“代理实际”输出只证明代理已经执行该命令，不代表任何成员已经复现或完成了对应贡献。

## 文件与固定范围

| 文件 | 用途 |
|---|---|
| 最小独立复核.py | 默认只向标准输出打印JSON，支持基础指标、动作回放和可选闭环回放 |
| 固定复核场景.json | 两个场景、四个主控制器、25个冻结输入的SHA-256及明确容差 |
| 预期结果.json | 从已经冻结的正式CSV提取的8个控制实例预期值 |
| 失败教学样本.json | 结果生成后按固定规则选出的一个失败教学样本，独立于主fixture |
| 代理实际复核输出.json | 本机完整20秒闭环回放、动作回放和指标复算实际输出 |
| 代理实际仅指标输出.json | 不导入Torch/SB3的基础NumPy指标复算实际输出 |
| 代理实际失败教学输出.json | 失败教学样本的实际复算输出 |
| 运行核验记录.json | 命令、解释器、数值误差、源文件与输出哈希的汇总证据 |

主fixture在本次复核前由任务约定：`single`和`three`各一条`rho=1.4, sample_id=0`场景，各比较`PID_N`、`PID_R`、校准`SAC_N`、校准`SAC_R`。PID的`model_seed=0`是固定控制器标记，两组SAC均使用`seed=11`的冻结best_model。禁止换成更有利的种子或初态。共读取8份NPZ与4份SAC模型，每份轨迹完整20秒。

这8个实例并不代表所有初态或种子，尤其不代表表现较弱的种子33。三轴固定例子的标称SAC控制代价实际上高于PID；不要把域外总体平均代价降低直接套用到每一条曲线。

## 已验证的运行环境

本机实际执行环境是`D:\Anaconda2024.06-1\python.exe`，Python 3.12.4、NumPy 1.26.4、Torch 2.10.0、Gymnasium 1.2.3、Stable-Baselines3 2.7.1。使用现有研究环境即可，无需安装新依赖。`metrics`模式仅导入标准库与NumPy；`policies`和闭环回放额外使用Torch、SB3、Gymnasium及包内已有PID/动力学实现。其他机器需保留完整成果包目录结构，并用具有这些依赖的Python环境运行。最低语法要求Python 3.10。

以下PowerShell命令从成果包入口运行，也可从任意目录使用脚本绝对路径。`-X utf8`保证标准输出重定向时使用UTF-8，`-B`配合脚本顶部`sys.dont_write_bytecode=True`避免生成`.pyc`。

```powershell
Set-Location -LiteralPath 'D:\applications-satellite.attitude.control.system\结项成果包'
$reviewScript = '09_结项文书与答辩/08_补充阅读与团队复核/02_最小独立复核/最小独立复核.py'

# 只复算保存轨迹，默认不写任何日志。
& 'D:\Anaconda2024.06-1\python.exe' -X utf8 -B $reviewScript --mode metrics

# 读取冻结模型并核对每个保存观测产生的下一步力矩，默认不重积分轨迹。
& 'D:\Anaconda2024.06-1\python.exe' -X utf8 -B $reviewScript --mode policies

# 推荐由成员执行：8实例全部回放完整20秒并重新检查末5秒保持判据。
& 'D:\Anaconda2024.06-1\python.exe' -X utf8 -B $reviewScript --mode policies --rollout-seconds 20
```

第三条命令本机实际约7.7秒，不需要重新训练。成功退出码为0，输出顶层`status="passed"`，8条`records`全部`passed`，每条完整回放应包含`full_horizon_acceptance_matches_saved=true`。任何哈希、身份、数值或成功判据不一致会退出码1并说明具体失败，不能把错误删掉后仍称复核通过。若只想先看前1秒，可将`20`改成`1`，它只检查短段，不能证明完整保持过程。

脚本不调用`report`、训练、选模或会写正式结果的核验入口。默认不创建文件或目录，运行前后核对25个绑定输入哈希。显式保存个人日志时，`--log-dir`必须指向整个原始项目外的新目录或空目录，脚本拒绝覆盖已有日志，并以UTF-8独占创建文件。比如：

```powershell
$personalLog = Join-Path $env:TEMP ('卫星项目成员复核_' + [guid]::NewGuid().ToString('N'))
& 'D:\Anaconda2024.06-1\python.exe' -X utf8 -B $reviewScript --mode policies --rollout-seconds 20 --log-dir $personalLog
# 新日志是 $personalLog/minimal_review_output.json，可自行另存到个人记录位置。
```

## 实际复算指标和预期值

单轴姿态误差从`theta_rad`重新包裹到`[-π,π)`后取绝对值；三轴从标量在前的单位四元数重新计算`2 atan2(向量部长度, |标量部|)`测地角；角速度从`omega_rad_s`重新取欧氏范数。随后用基础NumPy计算以下指标，未导入正式`compute_metrics`函数：

- 成功：完成20秒、无物理发散、最后5秒的每个采样点均满足姿态误差≤1°、角速度≤0.5°/s。
- 末段误差：最后5秒误差的均值和最大值，同时记录最大角速度。
- 全程RMS：误差平方对时间作梯形积分，除以实际20秒长度后开平方。
- 控制代价：`Σ ||torque[k+1]||² × (time[k+1]−time[k])`。保存行0力矩为零，行`k+1`对应上一采样间隔，不能错位或用初始零行代替末行。单位为`(N·m)²·s`，不是实际电能。
- 稳定时间：成功回合在此后持续处于误差带的第一个采样时刻，不是首次进入误差带。

下表数值来自正式CSV。脚本同时比对CSV、NPZ中保存的metadata和独立预期JSON。

| 轴 | 控制器 | 成功 | 稳定时间/s | RMS/° | 末5秒均误差/° | 控制代价/(N·m)²·s |
|---|---|---|---:|---:|---:|---:|
| 单轴 | PID-N | 是 | 4.70 | 9.532965 | 1.47089e-10 | 0.817834 |
| 单轴 | PID-R | 是 | 4.70 | 9.535382 | 0.050944 | 0.817276 |
| 单轴 | SAC-N，种子11 | 是 | 6.70 | 9.692772 | 1.37179e-6 | 0.385861 |
| 单轴 | SAC-R，种子11 | 是 | 6.25 | 9.777788 | 0.000727 | 0.520943 |
| 三轴 | PID-N | 是 | 4.50 | 12.956217 | 2.78641e-8 | 7.926811 |
| 三轴 | PID-R | 是 | 4.50 | 12.956217 | 2.78641e-8 | 7.926811 |
| 三轴 | SAC-N，种子11 | 是 | 7.84 | 14.167156 | 0.015786 | 8.935426 |
| 三轴 | SAC-R，种子11 | 是 | 6.26 | 19.963463 | 1.23220e-6 | 5.132960 |

动作回放对保存的`observation[k]`运行冻结控制器，核对`torque[k+1]`。SAC只作固定零动作偏置校准`clip(π(o)−π(0),−1,1)`再乘物理力矩上限。没有惯量输入、在线辨识或续训。PID回放复用已冻结PID实现；闭环回放复用原有共享动力学，因此这两项只检查冻结控制器与轨迹的一致性，不能称为独立动力学证明。

本机实际核验的8份NPZ指标与CSV最大绝对差为`8.674e-19`，原始状态重建误差数组最大差为`2.842e-14°`。保存观测回放共核对5,600个动作时刻，最大力矩差`1.431e-6 N·m`。完整20秒闭环回放共5,600步，8例成功判据与保存结果一致，最大状态分量差`1.022e-7`、最大观测分量差`1.192e-7`、最大力矩差`3.576e-6 N·m`。SAC使用float32推理，不同批大小产生少量舍入差异，完整回放的细小尾部数值可以不同；实际差值全部保存在输出中，没有改动正式结果。

容差在运行前写入fixture，实际执行没有因通过要求而放宽：保存轨迹指标为`绝对1e-9 + 相对1e-9`，状态重建的角度/角速度为`1e-8`，四元数范数为`1e-12`，零动作校准为`1e-7`，保存观测的力矩回放为`5e-6 N·m`。闭环状态/观测逐分量容差为`1e-5`，闭环力矩为`1e-4 N·m`，同时要求完整回放成功/发散判据与保存结果完全一致。这些闭环容差不同于从同一份NPZ重算指标的浮点比较容差。

## 单独复算一个失败教学样本

这是结果生成后选择的教学样本，选择规则为：冻结正式CSV中，三轴`SAC_R`、种子33、`success=False`且`failed=False`的回合，按`scenario_id`字典序取第一条。该规则选中`test_three_anisotropic_2_000`，是非等比例惯量迁移的初态0，倍率向量为`(1.4,1,1)`。它与主fixture的`ρ=1.4`等比例场景不同，不计入标量边界或新增正式统计，也不声称测试前已经选择它。

```powershell
& 'D:\Anaconda2024.06-1\python.exe' -X utf8 -B $reviewScript --mode metrics --failure-example
```

此命令仅复算这个NPZ，不加载种子33模型。预期`status="passed"`表示复算与保存结果相符，并不表示该控制回合成功。该回合的`success=false, failed=false, complete=true`：末5秒最大姿态误差`0.440062°`，在1°范围内；末5秒最大角速度`0.636984°/s`超过0.5°/s。因此失败属于角速度保持超限，未发生物理发散。最终角速度`0.356609°/s`虽然回到带内，仍不能代替末5秒每一点持续达标的要求。末段平均姿态误差`0.251705°`，RMS`12.519375°`，控制代价`6.039992 (N·m)²·s`。代理实际复算与CSV最大绝对差`1.111e-16`，3个绑定输入的哈希运行前后不变。
