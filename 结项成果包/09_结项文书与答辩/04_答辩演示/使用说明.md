# 答辩演示使用说明

双击 `答辩演示.html` 即可在现代浏览器离线打开。共12页，建议时长合计8分钟。左右方向键或页面按钮翻页，N显示讲稿，F切换演示布局，Esc退出演示布局。总览用于整体审阅。打印采用16∶9横向页面，浏览器打印时建议关闭页眉页脚，保持100%缩放并启用背景图形。

当前版本已载入V3正式结果并通过全量独立核验：12份SAC模型、1,200万交互步、10,920个测试回合。成功率、经验可用范围和控制代价图均来自随附冻结结果。团队、指导教师、分工和实际贡献仍需项目组据实补充。

`答辩演示阅读本.pdf` 是同一内容的12页16∶9打印阅读本，已用Poppler渲染并逐页检查。HTML适合翻页演示并查看逐页讲稿，PDF适合发送和打印；二者均不是可编辑PPTX。

## 正式结果填入

同目录 `defense_results.js` 与 `defense_results.json` 已按实际结果生成，并记录核心结论、实验清单及独立核验记录的SHA-256。也可导出JSON后点击页面“载入结果”。两种方式使用相同结构：

```javascript
window.INERTIA_DEFENSE_RESULTS = {
  verified: true,
  status: "verified",
  summary: ["由正式结果支持的研究结论"],
  boundaries: [{axis: "三轴", controller: "SAC-R共同", interval: "实际区间或无可用区间"}],
  training: {models: 12, steps: 12000000, episodes: 10920},
  figures: {
    success: "相对路径/成功率图.png",
    boundary: "相对路径/可用区间图.png",
    tradeoff: "相对路径/误差与代价图.png"
  },
  limitations: ["数据支持的适用范围与限制"]
};
```

示例中的规模与本轮实际清单一致。后续若重新训练，必须从新清单读取实际规模，不能沿用数字或核验标记。未完成或未通过核验的结果不得设置 `verified:true`。图片使用相对于HTML文件的路径；请整体保留成果包的目录结构。图片不存在时页面恢复待载入提示。

答辩页使用3条主要结论与3张主要结果图，完整五图及所有种子的详细结果可从最后一页“完整结果与五张图”打开。当前12页已按实际结果逐页渲染检查，检查记录与截图保存在 `_qa`。两组SAC的主结果均包含固定零动作偏置校准，原始动作消融另列，不能省略这一条件。

目录内 `填入正式结果.py` 可直接读取本轮实际 `核心结论.json`、实验清单及12份训练元数据，生成相同结构的JS/JSON。默认保持 `verified:false`。正式全量独立核验通过后，由主流程确认，再用 `--verified` 发布；脚本同时检查独立核验记录为passed和final_integrity，保留来源哈希。
