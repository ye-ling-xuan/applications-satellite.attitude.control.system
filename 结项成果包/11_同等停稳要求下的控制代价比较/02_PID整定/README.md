# 本次 PID 参数整定在做什么

以前的 PID 参数主要强调较快停稳。若直接拿它与动作较慢的 SAC 比较力矩平方积分，较慢的一方容易占便宜。本次重新搜索 PID 参数：先满足相同的停稳截止时间，再在通过数量相同的候选中，选择平均力矩平方积分较小的一组。

每个单轴或三轴任务分别选择 4、6、8 秒截止要求下的参数。正式实验的判定是：从截止时刻一直到 20 秒，每一个采样时刻都满足姿态误差不超过 1°、角速度范数不超过 0.5°/s，且没有发散。

## 使用的控制器

控制力矩为 `Kp × 姿态纠正误差 + Ki × 误差积分 − Kd × 角速度`，再经过与 SAC 完全相同的执行器限幅。单轴误差观测与三轴误差观测的符号约定不同，代码已按各自定义转换为纠正方向。

- 搜索包含 `Ki = 0` 的 PD 控制器，也包含非零积分增益的 PID 控制器。
- 三轴既搜索三个轴使用相同增益的情况，也搜索按标称惯量对角元素缩放的增益，并搜索各轴独立的增益。
- 非零积分采用条件积分抗饱和：力矩超限且积分会进一步加重超限时，暂停该方向的积分；能减轻超限的积分仍允许更新。
- 使用直接测得的角速度形成阻尼项。本研究没有噪声，因此没有额外低通滤波。
- 每组候选在不同初始场景中使用同一组固定参数，不在每个回合重新调参；每次回合重新清零积分状态。

`implementation_equivalence.json` 记录实现核验：批量候选传播与逐候选传播完全一致；相同参数下，与原项目已使用的 `tuned` PID 实现逐样本的真实姿态误差、角速度和力矩完全一致。此核验验证代码实现，不代替正式性能测试。

## 如何避免故意使用较弱的 PID

开发集有 32 个固定初始状态，验证集有 96 个固定初始状态，两者的种子与最终测试集不同。首先在较广的频率、阻尼参数网格及随机参数中搜索，再将各截止时间和各参数形式的靠前候选带入验证集，最后在验证集进行两轮局部参数细化。

参数只是用二阶系统固有频率、阻尼比生成，实际比较仍调用原项目的单轴动力学和三轴非线性刚体动力学，不使用线性化模型代替真实仿真。

所有搜索使用固定随机种子 `2026101744`。`search_design.json` 记录候选空间、搜索预算、细化规则和选择规则。搜索代码明确拒绝将 `test` 作为整定数据集。验证集被重复用于细化，因此其通过率只能用于选参，最终可靠性必须看未参与选择的独立测试集。

这是一次广泛但有限的参数搜索，不能声称找到了所有 PID 控制器中的全局最优解。

本次已完成的评估数量如下。细化阶段保留之前的候选，所以各阶段数量不能直接相加解释为互不重复的参数组。

## 文件怎么读

- `selected_pid.json`：单轴、三轴最终冻结的参数及验证表现。各轴目录中还有相同内容的单独文件。
- `single/`、`three/`：每个搜索阶段的候选参数、汇总排名和验证集逐回合指标。
- `*_candidates.json`：参数按照列表顺序对应同阶段排名表的候选序号。
- `*_ranking.csv`：每组候选的 4、6、8 秒通过数量、平均力矩平方积分等。表格按评估顺序保存，选优使用“通过数量最多，再比较成本”，不是仅按成本排序。
- `*_episodes.csv`：验证阶段每个候选、每个场景的指标，用来追溯具体失败原因。
- `运行日志.txt`：本次执行的候选数量、进度与阶段耗时。
- `核验_PID选择.py`、`selected_validation_recomputation.json`：从验证集逐回合 CSV 重新计算六组主参数和六组辅助参数的通过数、平均成本、最慢停稳时间，共 12 项核验全部通过。

`selected_pid.json` 另有辅助字段 `auxiliary_validation_time_margin_0_25s`：在已经评估的验证候选中，要求全部场景至少提前 0.25 秒停稳，再选平均成本最低的一组。这是正式测试前指定的辅助对照，用来观察主选择贴近验证截止边界时的可靠性问题；不改变主选择、不增加搜索，也不根据最终测试结果补选参数。没有满足条件的候选时记为 `null`。

力矩平方积分单位为 N²·m²·s，只是本研究的控制代价指标，不能直接解释成电能。
