# 同等停稳要求下的控制代价比较

本目录保存新授权的补充研究。研究问题是：两种方法都按时停稳时，强化学习能否比按相同目标重新整定的PID使用更低的力矩平方积分？

**实验已完成，本轮没有获得强化学习优于重新整定PID的控制代价结论。** 单轴、三轴结果与全部失败均保留。结论只适用于本次训练方案与测试条件。

先读[本轮工作说明](本轮工作说明.md)，也可以打开[结果总览HTML](结果总览.html)。详细数据见[研究结果说明](05_图表与分析/研究结果说明.md)，实验条件见[研究方案](01_实验方案/研究方案.md)。

| 目录 | 内容 |
|---|---|
| 01_实验方案 | 任务、判据、独立初态与冻结记录 |
| 02_PID整定 | 新目标下的参数搜索、验证与最终参数 |
| 03_SAC训练 | 旧策略部署调整、新训练及全部验证记录 |
| 04_独立测试 | 参数冻结后生成的回合指标与轨迹，含失败标记及冻结填充记录 |
| 05_图表与分析 | 结果表、图与清楚说明 |
| 06_核验 | 指标重算、动力学与动作复核记录 |
| 代码 | 本轮新增代码和有针对性的验证测试 |

原来的惯量研究、结项报告和答辩讲解包未被本轮代码覆盖。新增结果与旧研究的任务不同，不能把两轮成功率或代价直接串成同一条件下的改进。

运行入口：`运行研究.py`。使用原环境的Python与依赖，既有动力学通过只读导入复用。命令见[复核与运行说明](复核与运行说明.md)，全量独立核验状态见[核验报告](06_核验/独立核验报告.json)。
