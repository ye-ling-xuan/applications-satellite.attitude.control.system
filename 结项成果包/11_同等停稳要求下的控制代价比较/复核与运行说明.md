# 复核与运行说明

本研究复用上一级成果包的只读动力学代码。在完整项目目录中运行，不要把本文件夹移出后当作不依赖其他文件的程序。

## 日常复核

以下命令从项目根目录运行，使用本机已验证的Python环境：

```powershell
& 'D:\Anaconda2024.06-1\python.exe' -X utf8 -B -m pytest '结项成果包/11_同等停稳要求下的控制代价比较/代码/test_deadline_study.py' '结项成果包/11_同等停稳要求下的控制代价比较/代码/test_delivery.py' -q
& 'D:\Anaconda2024.06-1\python.exe' -X utf8 -B '结项成果包/11_同等停稳要求下的控制代价比较/运行研究.py' verify
```

第一条检查端点、持续停稳、实际力矩积分、物理等价、冻结与初态配对等反例。第二条会加载全部正式轨迹、从模型和独立PID公式重算动作，并用原始动力学重放，再重算全部回合指标；它不训练和选参，核验报告写入`06_核验/独立核验报告.json`。

如需重新生成结果说明与图表，依次运行：

```powershell
& 'D:\Anaconda2024.06-1\python.exe' -X utf8 -B '结项成果包/11_同等停稳要求下的控制代价比较/运行研究.py' report
& 'D:\Anaconda2024.06-1\python.exe' -X utf8 -B '结项成果包/11_同等停稳要求下的控制代价比较/生成说明阅读本.py'
```

第二条生成入口阅读页，并把独立审查发现的措辞更正应用到详细阅读本：区分评估记录与失败后的冻结填充、说明最终积分增益为0、列出物理失败记录数量。更正记录在`06_核验/阅读本文字更正记录.json`；此步骤不更改冻结代码、模型、参数或测试数据。报告生成本身不能代替独立核验；核验结果应同时查看。


这条命令只读核对原讲解包和原交付/技术冻结文件，不重跑原训练。不要使用原包的`--seal`来覆盖旧封装。

## 研究运行顺序

本轮实际顺序为：保存任务与独立初态清单→开发/验证上的PID整定与旧SAC动作缩放→A/B开发训练→固定B配置、种子和预算→六份正式从零训练→冻结全部参数/代码/模型→一次独立测试→全量核验→结果说明。

入口提供`design`、`legacy`、`pid`、`train`、`freeze`、`test`、`verify`、`report`。部署冻结后，入口拒绝重新训练或选参，测试目录也拒绝覆盖。希望重复训练或更换奖励时，应创建新的独立研究副本和空输出目录，不把新结果写回本轮冻结文件。

单轴种子42因Windows文件短暂占用在10万步中断，原记录保留，原种子按同一配置从零重跑。I/O包装器只对JSON替换重试，恢复过程另有记录，不改变动作、奖励、优化器或随机种子；不能将中断记录算成一份完成模型。

## 依赖
