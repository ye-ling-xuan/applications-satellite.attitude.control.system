正式结项比较使用 `正式训练_100万步`。旧目录保留工作过程，没有删除或改名；请按下表识别用途，避免混用模型与结果。

| 目录 | 标题与状态 | 用途 |
|---|---|---|
| `正式训练_100万步` | 正式交付：百万步 PPO 与验证集整定 PID | `run.py` 默认加载；对应正式实验、图表和技术报告 |
| `正式训练` | 早期探索：20 万步 PPO | 每模型请求 200,000 步、实际 200,704 步，验证间隔 20,000 步；已被百万步版替代，不参与正式统计 |
| `nominal/seed_11` | 早期联调：运行中断 | 保留联调日志和可能存在的检查点；缺少完整正式归档，不参与正式统计 |

原项目的旧卫星 PPO 模型存于 `../01_遴选原始参考` 的来源副本中，与本目录新环境的模型不同。

## 正式交付结构

`正式训练_100万步` 内包括 `nominal/seed_11、seed_22、seed_33` 和 `randomized/seed_11、seed_22、seed_33`，共六次独立训练。`nominal` 在固定名义环境训练；`randomized` 在既定范围内随机化惯量、扰动和测量噪声，范围以模型元信息为准。

每次请求 1,000,000 交互步，实际训练 1,001,472 步，因为 8 个环境、每个 rollout 256 步，需要完成整个采样批次。六次总请求 6,000,000 步，实际共 6,008,832 步。验证间隔为 50,000 步，验证场景预先固定，训练和选模不使用最终测试集。

| 文件 | 内容 |
|---|---|
| `best_model.zip` | 依据验证结果选出的模型，正式评估加载此文件 |
| `best_checkpoint.json` | 被选检查点的训练步数和验证分数 |
| `final_model.zip` | 完成全部预算后的模型，不保证是验证表现最好的模型 |
| `latest_model.zip` | 最新保存的策略及优化器状态，用于恢复工作 |
| `training_manifest.json` | 训练开始时的环境配置、超参数及代码哈希 |
| `training_metadata.json` | 实际训练预算、版本、选模结果及归档信息 |
| `validation_scenarios.json` | 固定验证集场景 |
| `validation_history.csv` | 各检查点的验证表现与选模记录 |
| `monitor_*.monitor.csv` | 各并行环境的逐回合奖励、长度和日志 |

正式目录顶层的 `pid_best.json` 保存验证集整定的 PID 参数，`pid_search_validation.csv` 和 `pid_validation_scenarios.json` 保存搜索记录及场景。PID 与 PPO 的正式测试共用环境、初态、随机数、力矩约束和评价标准。

## 最短使用入口

以下命令从成果包根目录运行。无需训练即可重新评估六个已交付模型和 PID，并将结果保存到新目录：

```powershell
python run.py evaluate --models '03_训练模型与日志/正式训练_100万步' --samples 50 --output '04_实验数据与图表/复现实验'
python run.py plot --models '03_训练模型与日志/正式训练_100万步' --results '04_实验数据与图表/复现实验'
```

从零复现正式训练预算和 PID 整定，使用不同的模型目录：

```powershell
python run.py train --mode both --seeds 11 22 33 --steps 1000000 --validation-interval 50000 --jobs 3 --output '03_训练模型与日志/重新训练_100万步'
python run.py tune-pid --output '03_训练模型与日志/重新训练_100万步'
```

然后将评估、绘图命令的 `--models` 改为 `03_训练模型与日志/重新训练_100万步`，输出到另一个实验目录。`--jobs 3` 表示最多三个训练同时执行，并非减少为三个模型。请勿省略验证间隔参数：当前 CLI 默认值为 20,000，与正式训练使用的 50,000 不同。

若需要恢复训练，加 `--resume`；策略及优化器可恢复，中断时环境随机数和未完成 rollout 不保证恢复。因此完全重现正式模型应从零训练，而评估已保存模型通常更容易复现。实际环境版本见 `../02_配置与方法/environment.json`。
