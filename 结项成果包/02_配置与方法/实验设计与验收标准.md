# 单轴卫星姿态控制实验设计与验收标准

## 研究任务

在相同动力学、观测信息与执行器约束下，比较经过验证集整定的 PID、固定物理条件训练的 PPO，以及物理参数随机化训练的 PPO。研究惯量偏差、外部扰动和传感器噪声对控制性能的影响。结论依据真实测试数据，允许出现改进无效或 PID 更好的结果。

## 模型与单位

单轴刚体惯量默认为 1 kg·m²；状态为姿态角和角速度，内部单位分别为 rad、rad/s。控制力矩限幅为 ±0.5 N·m；动作归一化为 [-1,1]，所有控制器通过同一个环境更新接口施加力矩。每步使用常加速度精确更新，步长 0.05 s，完整验证时长 20 s。执行器死区、正弦扰动、恒定扰动、脉冲扰动和观测噪声均显式配置。

PID 与 PPO 获得相同的带噪姿态误差及角速度，控制器不可读取真实惯量或扰动力矩。PID 的微分项使用角速度测量，积分项限幅并采取条件积分，避免饱和时持续累积。

普通 PPO 与随机化 PPO 使用相同网络、奖励和训练预算，改动项是训练物理条件的分布。实际执行参数以随模型保存的配置为准；随机化不能自动等同于鲁棒性提升。

## 数据隔离与公平比较

训练、验证和最终测试的随机种子与场景分别记录。PID 参数由验证场景选择，PPO 检查点仅由验证场景选择；最终测试结果不用于回填选模。每个控制器面对相同初态和相同噪声、扰动随机数序列。

各 PPO 类型使用至少三个独立训练随机种子。测试时保留所有模型，不能只展示最佳种子的结果。汇总同时给出每个种子的成功率以及跨种子的均值和标准差；统计不将同一模型的所有回合视作独立训练重复。

测试分别检查正常控制、惯量变化、正弦扰动、观测噪声、脉冲扰动和组合工况。组合工况单独标注为压力测试；训练范围内外的情况以场景配置判断，不把有限场景结果推广到所有卫星任务。

范围标记仅相对于随机化PPO的训练分布。测试初态样本和噪声种子与验证分开，但部分工况类型及参数等级曾出现在验证集中，不能据此声称对从未见过的工况类型泛化。提前失败的控制代价因轨迹较短而可能偏低，需结合成功率、失败率与有效时长解读。

## 验收指标

| 指标 | 定义 |
|---|---|
| 成功率 | 完成整个仿真，最后 5 s 的真实姿态误差持续 ≤1°，真实角速度持续 ≤0.5°/s，且没有发散 |
| 稳定时间 | 两项状态自该时刻起直到仿真结束始终满足阈值；持续区间必须至少 5 s。未达到时为空值，并按失败计数 |
| 末段误差 | 最后 5 s 真实姿态误差的平均绝对值；失败回合也保留误差，不能删除 |
| 全程 RMS 误差 | 整个有效轨迹的姿态误差均方根；与收敛阶段及初态有关 |
| 超调 | 从初始误差方向越过目标后的最大角度偏差，不把初始角度当作超调 |
| 控制代价 | 实际执行器力矩平方的时间积分 ∫u²dt，单位 (N·m)²·s；不称为卫星实际电能或燃料消耗 |
| 峰值力矩 | 实际执行器力矩绝对值的最大值；外部扰动力矩单独记录 |

这些阈值是本项目约定的仿真验收条件，不是学校优秀项目评分规则或在轨产品技术指标。结项是否优秀仍由学校评审决定。

## 交付验收

1. 原始文件的 SHA256 核验全部通过，新增内容仅在本成果包内。
2. 核心回归检查覆盖随机数复现、动力学、积分饱和、持续稳定判定和超调定义。
3. 交付新环境训练的模型、配置、训练记录及来源标识；历史模型只归档。
4. 交付测试场景、逐回合指标、全部轨迹、汇总表和主要图表。
5. 独立提供三轴 PID 演示及四元数边界修正；不声称完成三轴强化学习。
6. 总说明和技术报告使用运行结果，列出失败、限制以及未完成的研究内容。
