# 新增材料技术审查与融合依据

本次新增材料来自 `中期前任务收尾/大一立项AI在卫星姿态调整中的应用`。原资料提供了实用的三轴刚体强化学习环境、单轴 PPO 和三轴 PPO/SAC/TD3 模型，以及 PID 对比与扰动实验。原文件保留不变；原结果属于历史成果，新结果由成果包中的统一环境重新计算。

## 1. 模型与接口核实

下表直接读取模型 ZIP 内的 SB3 `data` 元数据，不根据文件名推测。

| 历史模型 | 实际交互步数 | 保存的随机种子 | 观测 | 保存的动作范围 |
|---|---:|---|---|---|
| 单轴 PPO | 200704 | null | 当前角度、角速度，共 2 维 | ±2 N·m |
| 三轴 PPO | 800768 | null | 最短旋转误差向量、角速度，共 6 维 | 各轴 ±2 N·m |
| 三轴 SAC | 800000 | null | 同三轴 PPO | 同三轴 PPO |
| 三轴 TD3 | 800000 | null | 同三轴 PPO | 同三轴 PPO |

PPO 的少量超出是 rollout 批次补齐，不是额外一轮训练。三轴历史模型的惯量为 `diag(1.2,1.0,0.8)`，积分步长 0.01 s；训练回合最多 5 s，旧评价回合最多 20 s。奖励是误差、角速度和力矩平方的负和，满足约 1.146° 角度与约 1.146°/s 转速时提前结束并给一次成功奖励。

三轴 SAC 保存的配置包括熵系数 0.05、学习率 0.0003、`learning_starts=20000`。TD3 保存的配置包括学习率 0.001、`learning_starts=20000`、动作探索噪声 sigma 0.2。SB3 离策略探索噪声作用在归一化动作上，因此在 ±2 N·m 执行器下该 sigma 对应约 0.4 N·m，而不是原分析文中写的 0.2 N·m。

原目录没有保存训练日志、最优检查点和 replay buffer，四份模型都未保存显式训练种子。可以核查保存模型的步数和超参数，但不能将单份模型解释为多种子统计，也不能据此保证原训练轨迹可逐步重现。SAC 续训脚本的 `learn(total_timesteps=800000, reset_num_timesteps=False)` 会额外增加 80 万步；当前模型元数据只有 80 万步，没有证据显示当前模型经历过该续训分支。

## 2. 旧比较中的限制

1. 干净条件下的 `compare_rl_pid.py` 与 `compare_rl_algorithms.py` 在第一次满足环境成功阈值时终止。随后报告的“纠正时间”只要求轨迹剩余采样点满足 1°，甚至可能只剩一个点，不能证明持续保持。不同算法的末段误差来自不同结束时刻，不能当作共同 20 s 的稳态误差。
2. 鲁棒性比较已固定跑满 20 s，这是有用基础。但成功判据仅考虑姿态误差，未要求转速小于统一阈值，也未要求连续保持至少 5 s。
3. 29 条初姿态列表包含四次相同的零姿态，只有 26 个不同姿态。平均时会给零姿态重复权重。只报告成功案例的平均纠正时间，也可能掩盖大量失败。
4. 旧三轴 PID 固定使用 `Kp=3, Ki=0.5, Kd=1`，直接差分误差，并从零初始化上一误差，因此首次动作会出现微分冲击；输出饱和时积分仍累积。该特定 PID 的不足不能推广为所有 PID 均比 RL 差。
5. “SAC 的熵塌缩导致失败”“TD3 探索噪声过大导致失败”“PPO 更适合短回合”的因果解释缺少独立消融验证，应作为待验证假设。`explained_variance` 高也不能替代闭环成功率。
6. 原三轴 PID 四元数工具缺少 `q` 与 `-q` 的同姿态处理。历史 RL 环境已经处理普通双重覆盖，但任意目标姿态时还需明确误差和角速度的坐标系。本次目标为单位四元数，统一环境使用本体系最短旋转修正。

## 3. 融合时采用的共同条件

单轴保留上一版成果包的动力学、步长 0.05 s、力矩限幅 ±0.5 N·m 和观测符号；三轴使用步长 0.02 s、RK4、惯量 `diag(1.2,1.0,0.8)`、各轴 ±2 N·m，包含欧拉陀螺耦合项。所有新训练模型使用归一化动作，所有控制器评价时受到同一执行器限幅。历史模型动作先转换为物理力矩再映射到共同执行器。

因此，历史三轴模型复测属于从 0.01 s 到 0.02 s 的部署测试；历史单轴模型复测还包含从 ±2 N·m 到 ±0.5 N·m 的执行器部署变化。它们的旧 CSV 和新部署结果分开保存，不能把旧模型与重新训练模型的差异全归因于算法改进。

全部共同评价固定运行 20 s，并要求末 5 s 同时满足：姿态误差范数 ≤1°、角速度范数 ≤0.5°/s，且没有发散。成功前不提前终止。状态发散后保留失败标志，冻结状态并填充统一长度，后续控制力矩置零；这属于失败记录的填充，不能解释为完成真实 20 s 控制。指标提供失败时刻与实际运行时长。

验证集为 16 个场景，独立于正式测试的初态和噪声种子。PID 参数和 RL 检查点只用验证集选择。正式测试包括名义、惯量变化、持续扰动、观测噪声、脉冲和综合压力场景，每个场景的初态和外部噪声在控制器之间配对。

## 4. 可以支持的改进主张

PID 的改进包括角速度阻尼、条件抗积分饱和、验证集选参与可选角速度滤波。单轴历史基线为上一版正式选择的 `4/0/3` PD，三轴历史基线为原资料的 `3/0.5/1` PID。滤波额外增加相位滞后，不能先验保证全面改善；若验证选中 alpha=1，应如实写“没有选择额外滤波”。

强化学习采用相同轴环境、相同训练分布、相同交互预算与多个独立种子，并完整记录算法各自更新机制和配置。最优模型按共同验证分数选择，并保留最终模型。重新训练或调整算法后，改进必须通过正式测试的成功率、误差和力矩平方积分一起判断。某个算法仍有失败，或更精确但耗费更大，都属于应报告的结果。

验证复核结果保存在同目录 JSON 中。其中 PID 文件包含重新计算全部候选后的选值一致性，单轴模型文件包含独立重加载九个最优模型后的逐项指标差异。这些文件只读取验证场景，不使用正式测试集。
