当前11图依次为：训练与测试数量、柔性模型、控制结构、训练验证、参数与验收、刚体对比、惯量及执行器探索、柔性成功率、控制代价、统计区间、独立核验。

多面板图插入Word后应保持文字可读。可放在横向页面，或按完整面板拆分为同一图号的(a)、(b)等；须保留全部控制器、测试组、坐标单位、图例和说明。保留LQR对照，不只截取PPO结果。图9是对数坐标；图7各实验协议的代价不横向排名；图11的归一化动作差是无量纲量。力矩平方积分不解释为实际电能。
