# 前期结果图：来源、图注与重绘

本目录仅从项目已冻结的正式逐回合记录重算和绘图，不训练、不调参、不修改原始结果。

## 图6：刚体多算法与部署修正

建议插在结题报告“研究结果”中，介绍刚体阶段PID整定和零观测动作偏置修正的段落之后。

**建议图注：**（A、B）单轴与三轴耦合任务中，原始PID、验证集整定PID及扩展滤波候选PID的持续停稳成功率；（C、D）同一PPO、SAC、TD3网络修正零观测动作偏置前后的成功率。柱为合并成功率，深色点为三个训练种子的成功率。每回合20秒，末5秒持续满足角误差不超过1°、角速度不超过0.5°/s；PID各180场景，RL每算法为三个种子复用同一组180场景，共540回合。0%表示未满足持续停稳验收，不表示全部物理发散。两任务的输入上限、状态维数不同，不跨轴数直接排名控制代价。

## 图7：惯量与执行器探索结果

建议插在结题报告“研究结果”中，介绍惯量随机化、执行器一阶滞后与纯延迟探索的段落之后。

**建议图注：**（A）惯量倍率ρ=0.5、0.6、1.4、1.5的保留域外测试，比较标称整定PID、标称训练SAC与随机化训练SAC。SAC均为校准部署，深色点为三个训练种子的成功率；PID每任务120场景，SAC每组为三个种子复用120场景。（B）标称训练SAC与PID均全部成功时，将PID均值设为100%，比较力矩平方积分、停稳时间与全程RMS误差，三者均越低越好，表明较低力矩代价伴随响应更慢及误差更大。（C、D）仅使用原12号执行器正式版本的域内测试，比较重新整定PID与三个独立训练的SAC补偿模型的成功率及完整22秒实际力矩平方积分；各控制器1536回合来自256初态×6参数。惯量任务为20秒、末5秒验收；执行器任务为8～22秒持续验收，不跨研究协议比较代价。力矩平方积分不等于实际电能；未将15号训练修正版的开发诊断数值混入原12号正式测试。

## 重绘和核对

在仓库根目录运行：

```powershell
python -X utf8 -B 结题报告配图/06_绘图代码与数据/前期结果/生成前期结果图.py
```

依赖为`matplotlib`和`numpy`，中文字体优先Microsoft YaHei。PNG为240 dpi，SVG保留矢量文字，适合报告排版。

`图表数值.json`保存图中成功数、回合数、成功率、代价均值及各种子成功率；`来源与核对记录.json`记录原始资料及图像SHA256。脚本将逐回合重算值与正式摘要逐项校对，成功率和均值容差为1e-12，不根据图中文字抄录近似值。每项图表均已目视检查，未发现中文缺字或遮挡关键数值。
