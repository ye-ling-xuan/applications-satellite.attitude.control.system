# 完整图表版的绘图资料

本目录保存11图版报告的绘图代码、输入数值与来源记录。所有脚本均读取已保存的项目记录，不启动控制器训练或新增测试。

|目录或脚本|负责内容|输入与核对记录|
|---|---|---|
|[训练与方案](训练与方案/)|图1、图4、图5；将原有模型与结构图复制为图2、图3|`制图数值.json`、`来源与哈希.json`|
|[前期结果](前期结果/)|图6刚体对比、图7惯量与执行器探索|`图表数值.json`、`来源与核对记录.json`；逐回合结果与正式摘要核对|
|[柔性结果](柔性结果/)|图8成功率、图9代价、图10统计区间、图11核验|`制图输入`保存原样副本，其他CSV/JSON保留完整数值和来源|
|[生成报告阅读版与核对.py](生成报告阅读版与核对.py)|将根报告转换为离线HTML，生成来源清单并检查图片、图号、链接与SHA-256|输出配图目录中的`完整图表来源清单.json`与`核对结果.json`|

在项目根目录按下列顺序运行，即可重绘和生成阅读版：

```powershell
python -X utf8 -B 结题报告配图/06_绘图代码与数据/训练与方案/生成训练与方案图.py
python -X utf8 -B 结题报告配图/06_绘图代码与数据/前期结果/生成前期结果图.py
python -X utf8 -B 结题报告配图/06_绘图代码与数据/柔性结果/生成柔性结果图.py
python -X utf8 -B 结题报告配图/06_绘图代码与数据/生成报告阅读版与核对.py
```

需要Python及matplotlib、numpy、Pillow、Markdown，绘图使用Microsoft YaHei中文字体。原始研究记录应保留在当前项目的原路径；完整来源清单逐图注明这些路径。HTML与图片使用相对链接，离线阅读时将根报告与整个`结题报告配图`目录一起复制。
