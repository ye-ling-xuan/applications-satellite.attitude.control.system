# 柔性附件结果图的制图资料

本目录支持图08—11的复现。图表只重绘已有冻结结果，没有训练、重新调参或新增测试；原研究文件不变。

## 文件与数据

- `生成柔性结果图.py`：生成四张PNG和四张SVG，输出到`../../05_完整图表版/`。
- `制图输入/`：研究结果摘要、配对统计、独立核验、冻结方案和核验源码的原样副本。
- `图08_09_完整制图数据.csv`：3组×9种控制器的原始通过数、成功率、越界数、力矩平方积分和残余振动RMS，共27行。
- `图10_18项主要比较原值.json`：全部18项主要比较，保存未经绘图取整的均值、上下界和置信度。
- `图11_核验指标原值.json`：图11使用的汇总值、来源字段及其单位解释。
- `名称映射.json`：图中方法名称与研究源码键的对应，以及冻结参数。三种普通PID参数及优化ZVD方案的积分增益为0，图中准确标为PD；原始文件键保留不变。
- `来源与导出清单.json`：原研究路径、原样副本与全部图文件的SHA-256。

## 复现

在项目根目录执行：

```powershell
python 结题报告配图/06_绘图代码与数据/柔性结果/生成柔性结果图.py
```

需Python、numpy和matplotlib；建议使用Microsoft YaHei或SimHei中文字体。输入副本随本目录保存，脚本优先使用副本；如原研究路径仍存在，会检查其SHA-256与副本一致。

## 阅读边界

图08完整保留九种方法，包括优化LQR。灰色表示未持续达标但未越界，红色表示越出预设模型范围，不等同于实物损坏。

图09为完整0—22秒时窗的平均力矩平方积分，单位N²·m²·s。存在未成功回合的方法加斜线，不能仅依据其积分较小宣称效率优势。LQR和三个PPO模型各组均全部通过，LQR代价均更低。对数坐标左端为0.003，不是0。

图10直接采用原统计结果，按128个初态成组、保留每初态五个频率进行200,000次配对bootstrap。18项主要比较经Bonferroni校正，双侧区间置信度99.7222%。绘图将比例差乘100变为百分点，没有重新抽样或重算区间。

图11状态误差字段是原核验源码对原始状态分量数值所取的最大值，角度为rad、角速度为rad/s；未将不同物理量共用坐标轴或解释为同量纲范数。`max_policy_action_error`是归一化策略动作差，单位不是N·m。命令力矩和代价的检查通过由核验源码断言及总体`passed`记录支持，原文件未保存这两项误差最大值，因此图中不编造为0。复算PPO动作仍复用原策略实现。
