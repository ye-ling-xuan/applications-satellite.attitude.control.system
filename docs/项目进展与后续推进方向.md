# 卫星姿态控制项目：当前进展与下一步

更新日期：2026 年 10 月 5 日

**目前已经完成单轴仿真和初步对比。后续建议围绕三个任务推进：规范环境接口、研究 PID + PPO、扩展到三轴。**

## 1. 我们在做什么

分别用传统 PID 和强化学习 PPO 控制卫星姿态，再在相同条件下比较：谁调整得快、误差小、控制代价低。

后续把 **PID + PPO 组合控制**作为主要研究方向，同时保留单独 PID、单独 PPO 作为对照。

目前使用库里的 PPO 算法，在我们自己的环境中重新训练，训练是有效的。后续重点是改进训练方法并验证效果。

## 2. 已经完成什么

- **统一仿真环境：**PID 和 PPO 使用相同的动力学、力矩上限和评价标准。
- **完成基础代码：**可以训练模型、保存结果、画图和重复实验。
- **完成训练对比：**两组 PPO 各训练 5 次，每次约 20 万步。
- **完善代码检查：**49 项测试通过，已配置 VS Code 运行入口。

已有组合控制初稿是“PD + PPO 修正力矩”，尚未完成带积分项的 PID + PPO，也未验证组合算法的优势。

## 3. 结果怎么样

我们降低了奖励中对“使用力矩”的惩罚，让 PPO 更积极地调整姿态，效果明显改善。

| 方法 | 基础工况成功率 | 全部测试工况成功率 |
|---|---:|---:|
| PID | 100% | 100% |
| PPO，力矩惩罚 0.5 | 93.3% | 42.9% |
| PPO，力矩惩罚 0.05 | 100% | 97.6% |

说明：PPO 结果是 5 次独立训练的平均值，每个模型测试 84 个场景。基础工况与训练范围一致；全部工况还包含惯量变化、初始状态变化和外部扰动。

成功要求：完整运行 10 秒，最后至少 1 秒姿态误差不超过 1°、角速度不超过 0.2°/s，且未触发失败。

**当前结论：PPO 已经能较好地控制，但还不能说比 PID 更好。**

在基础工况下，改进后的 PPO 平均约 4.95 秒稳定，PID 约 3.43 秒。PPO 的力矩平方积分较小，但调整更慢，而且部分低惯量场景仍未成功。该积分是控制代价指标，不是实际电能。

## 4. 后续三个主要任务

| 任务 | 要做的事 | 完成后得到什么 |
|---|---|---|
| **规范环境和接口** | 统一状态、动作、单位、扰动、力矩限制和评价方式 | 三种方法可以公平比较，并共用三轴扩展接口 |
| **研究 PID + PPO** | PID 提供基础控制，PPO 学习额外的修正力矩 | 检验组合方案能否改善误差、抗扰动或控制代价 |
| **扩展到三轴** | 加入三轴动力学和四元数姿态表示，适配三种控制方法 | 在更完整的姿态模型中验证结果 |

建议顺序：**完善共享接口 → 单轴验证 PID + PPO → 三轴扩展 → 三种方法统一对比。**

组合方案先采用“最终力矩 = PID 力矩 + PPO 修正力矩”，限制修正幅度和总力矩。PPO 需要在组合环境中重新训练；如果使用完整 PID，还要处理积分状态的观测、重置和防饱和。

下一轮先完成单轴组合方案，比较 **PID、PPO、PID + PPO** 在基础工况、惯量变化和外部扰动下的成功率、调整速度、误差和控制代价。不能因为加入了 PID，就默认组合一定更稳定。

测量噪声、延迟和真实执行器模型作为后续加项，逐个研究。

## 5. 建议怎么分工

| 方向 | 负责的事 |
|---|---|
| 仿真与 PID | 完善共享接口，准备三轴模型和传统控制基线 |
| 强化学习 | 实现 PID + PPO 组合，调整奖励并完成多次训练 |
| 实验与复查 | 对比三种方法，整理表格和曲线，分析失败原因 |
| 文档与汇报 | 更新进度，整理组会和答辩材料 |

具体人员由组内确定，人数少可以合并。

做实验时遵守三点：**比较条件相同；每次明确改变了什么；用新的测试场景检验，不能只挑表现好的模型或曲线。**

详细代码、命令和实验记录见项目根目录的 README.md；当前结论来自单轴仿真，三轴控制和真实执行器效果仍需后续验证。
