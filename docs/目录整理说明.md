## 恢复方法

本机归档位置：项目外层的 `归档/2026-10-05目录整理/`。

- `project/` 保留被归档文件在原项目内的相对路径。
- `manifest.json` 记录每次移动、保留的参考文件及删除的缓存。
- 恢复某个文件时，将它复制回同名相对路径；目标存在时先核对，避免覆盖当前文件。
- 原本已提交的历史文件也可以通过 Git 历史恢复。
- `.conda` 属于旧本地环境，恢复后是否可用仍需单独检查；当前运行使用项目外的 Anaconda。
