# 第03步支撑材料

本步仅使用第二版刚体统一比较结果。原件位于“结项成果包/07_单轴三轴多算法对比”和“结项成果包/multi_algorithm_benchmark”。

| 要核查的问题 | 原件 |
|---|---|
| 总统计、模型数与边界 | 新融合分析.md、result_summary.json、实验约定.md |
| 同场景逐回合比较 | results/episode_metrics.csv、summary.csv、evaluation_manifest.json |
| PID改善归因 | models/pid_configs.json、results/paired_improvements.csv；开发核验/PID验证选择复核.json |
| 偏置是否固定与逐模型配对 | models/policy_calibration_manifest.json、results/policy_calibration_pairs.csv |
| 训练是否真实及种子差异 | models目录各正式训练元数据和验证历史，来源清单逐文件登记 |
| 算法和环境实现 | envs.py、controllers.py、training.py、vector_training.py、improvements.py、metrics.py |
| 历史一致性限制 | 核验记录.json；记录训练与现源码的留档差异，勿扩大核验含义 |

图表/01_PID配对改进.png和图表/02_同模型偏置修正.png均原样复制自正式results/figures，并在[来源清单](来源清单.json)登记source、copy、字节数与SHA-256。其他材料仅索引原件，不重复复制大型模型或全量轨迹。

本步成功率不能与惯量专项的域外成功率直接相减，因为后者关闭扰动与噪声、使用不同模型及测试场景。
