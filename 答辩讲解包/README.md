# 从这里开始：卫星姿态控制项目答辩讲解包

这个项目研究的是：怎样让卫星转到指定方向、停下来并保持住，以及强化学习在什么条件下能提供帮助。控制对象是卫星的朝向，不是卫星的飞行轨道。

本包按实际研究推进的顺序整理。先看每一步的`本步讲解.md`，读懂后再看`答辩与论文用稿.md`。图表放在各步骤的外层；来源代码、完整关键统计表、模型或代表轨迹放在该步骤的`支撑代码与数据`里。代码与数据是原成果的副本，原有工程保持原样。

想连续阅读，可打开[按顺序阅读.html](按顺序阅读.html)。需要逐个文件阅读，就从下表第一步开始。

## 读之前先知道的几个词

| 词语 | 在本项目中的意思 |
|---|---|
| 姿态 | 卫星朝哪个方向 |
| 姿态误差 | 当前朝向离目标朝向还差多少 |
| 角速度 | 转得多快；方向对了但还在转，也可能马上偏出去 |
| 力矩 | 让卫星加速转动或刹车的作用 |
| 转动惯量 | 物体有多难被转起来或停下来 |
| PID | 根据方向偏差、偏差累积和转动速度计算控制指令的一类反馈方法 |
| 强化学习 | 在仿真中反复尝试，根据奖励学习“看到什么状态，该输出什么动作” |
| 一个回合 | 一次完整的控制尝试；正式测试通常运行20秒，失败也计入结果 |
| 一个训练种子 | 一次独立训练使用的随机编号；同一种算法要训练多次，检查结果是否稳定 |
| 标称 | 预先选定的正常参数值，不是“最好的”意思 |
| 域外 | 参数超出所声明训练范围的保留测试条件；具体范围必须随实验版本说明 |
| 校准 | 本项目中减去网络在零误差、零转速时的固定动作偏置；不是重新训练 |
| 控制代价 | 力矩平方随时间的累计，用于比较控制负担，未测量实际电量 |

## 三轮实验怎样接起来

```text
V1：先把单轴模型、PID、PPO和评价流程搭起来
  ↓ 发现需要更强的基线、更完整的三轴比较
V2：单轴/三轴分别比较PID、PPO、SAC、TD3，并拆分整定与校准作用
  ↓ 综合随机化混合了多种变化，难以单独解释惯量的影响
V3：只改变训练惯量，用SAC和强PID做受控研究，保留域外测试
  ↓ 汇总实际收益、失败与限制，提出下一项目的独立方向
```

V1、V2、V3的环境与测试范围不完全相同。可以汇总各阶段做了多少工作，但不能用V2的成功率和V3的成功率直接宣称算法进步了多少。每一步的解释都标出对应版本。

## 准备答辩或论文时怎么用

第一次学习按01→07读。答辩可把篇幅集中在05、06、07，前面解释研究基础。若准备8分钟讲解，可暂按01用30秒、02用45秒、03用45秒、04用70秒、05用80秒、06用140秒、07用70秒分配；实际时长以学校要求为准。

论文可以把01作为引言，02与04的模型和算法作为方法，把03、05、06整理成分阶段实验，再用07写讨论和结论。各步骤的“论文用稿”提供可编辑段落，正式成文还需统一符号、图号、参考文献与作者实际贡献。

核对来源及关键数字可使用[运行与复核说明](运行与复核说明.md)中的只读命令。完整实验的全部轨迹仍在原`结项成果包`，本包选入的示例轨迹用于读图与说明，不能替代全体统计。

本次工作是整理和讲解，没有增加训练、改变旧实验或验证新的优势结论。现有软件结果与学校是否评优、团队是否亲自复现、是否正式提交是不同事项。
