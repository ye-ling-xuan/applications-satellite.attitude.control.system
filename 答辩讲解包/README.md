# 答辩讲解包：柔性附件论文版

建议先打开[按顺序阅读.html](按顺序阅读.html)，公式和图表可离线显示。想直接开始写作，打开[论文正文初稿](论文正文初稿.md)和[论文大纲与证据对照](论文大纲与证据对照.md)。

这次把项目重组为8步，**柔性附件振动抑制是最终主实验**。惯量变化、纯延迟和一阶执行器滞后压缩成第04步，只用SAC作为代表算法；不是把不同物理任务伪装成一个通用权重模型。

|顺序|内容|阅读目的|
|---|---|---|
|01|研究问题与论文主线|明确全文要回答什么|

|03|多算法对比与部署改进|解释统一比较与基线整定|
|04|惯量与执行器误差探索|用简短阴性结果说明转向原因|

|06|PID与PPO学习补偿设计|看懂网络补偿什么、如何选模|
|07|柔性附件对比实验与独立核验|看最终结果、统计和局限|
|08|研究结论与论文答辩组织|把证据转为论文和答辩结论|

每一步外层是精华讲解、用稿和图表，内层“支撑代码与数据”是材料说明与逐文件来源清单。完整模型和大体积轨迹保留在原`结项成果包`，以路径和SHA-256对应；请将两个包放在同一项目目录，单独拷走讲解包不包含全部轨迹。

本次新增17,280回合测试，三个冻结PPO在三组各640场景中全部完成任务。补充搜索PID分别完成597、571、580回合，多种子配对统计支持成功率改善。优化LQR也全部成功且控制代价更低，因此结论是相对所比较PID有效，不能概括成AI全面优于传统控制。
