# 仅惯量随机化训练接口

新增实现位于 `inertia_generalization/`，入口为 `run_inertia.py`。所有命令在 `结项成果包` 目录运行。V1/V2源代码、模型及实验输出不修改。

## 正式训练

```powershell
python run_inertia.py freeze
python run_inertia.py tune-pid --axes single three
python run_inertia.py train --axes single three --modes nominal randomized --seeds 11 22 33 --jobs 3
```

也可逐份训练：

```powershell
python run_inertia.py train --axis three --mode randomized --seed 11
```

正式训练强制100万交互步、8环境、每10万步验证、种子11/22/33，不接受改变物理配置。SAC设置与研究计划一致。训练从零开始，不续训旧模型。输出目录为 `02_模型与验证日志/{single,three}/{nominal,randomized}/seed_{11,22,33}`，存在目录立即报错，避免覆盖。

可直接调用 `training.train_model(output_dir,axis,mode,seed,steps=1000000,n_envs=8,validation_interval=100000,development=False)`；返回 `training_metadata.json` 同内容的字典。调用者可使用进程池并行多个独立训练，但每进程内部固定PyTorch单线程。

## 开发联调与隔离

```powershell
python run_inertia.py train --axis single --mode nominal --seed 11 --steps 32 --n-envs 2 --validation-interval 32 --development
```

开发结果明确标记 `eligible_for_final_research=false`，默认写入 `06_开发联调/models`，不进入正式12模型。开发运行也使用共同20场景验证，不读取正式测试响应。正式训练的默认命令不会退化为开发预算。

## 物理与随机流

`make_env(axis,mode,config=None)` 返回Gymnasium环境。`EpisodeSampler` 使用 `SeedSequence(seed).spawn(3)` 分离初态、惯量、观测噪声种子；标称和随机化每回合初态流匹配。标称惯量倍率恒1，随机化倍率为每回合独立 `U[0.7,1.3]`，回合内固定。全部外部扰动、脉冲、测量噪声为0，非零配置将拒绝。三轴惯量还检查刚体三角不等式。

单轴/三轴Gym环境复用V2 `BatchSatelliteEnv`，快速三轴环境继承已验证的V2批量RK4、SB3自动reset、Monitor与终止观测语义，仅替换reset采样器。Gym接口为 `reset(seed=...,options=scene)` 与 `step(normalized_action)`，动作范围[-1,1]。控制器观测仍只有姿态误差与角速度，不包含惯量。初态实际抽样、每回合倍率、rank、流种子和episode编号写入 `training_episode_initial_states*.csv`，可核对实际样本和回合数。

## 选模与保存

两组每10万步和训练结束均在同一20场景验证集上计算原始动作和校准动作表现。只按校准分数 `100*success_rate-rms_error_deg-0.2*control_cost` 选择best；同分依次按更低RMS、更低控制代价、更早step选择。原始动作始终使用同一选中检查点作消融。

每次保存 `validation_history_raw.csv`、`validation_history_calibrated.csv`、`best_checkpoint.json`、`latest_checkpoint.json`。best记录校准偏置 `predict(zeros)`，不根据测试响应调整。完成后保留best/final/latest模型、完整replay buffer、环境/超参数/软件版本、源码哈希、模型与replay哈希、实际交互步和梯度更新数。训练前后核对运行源码；中途改变运行源码将标记失败，需要审核，不能直接混作正式证据。

`session_status.json` 区分initializing/running/complete/incomplete。异常时尝试另存interrupted模型和replay，不自动覆盖/续训已有目录。未完成训练不能计入12份正式成果。
