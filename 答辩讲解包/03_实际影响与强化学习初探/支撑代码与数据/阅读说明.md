# 本步支撑材料怎么读

本目录保留第一版正式PPO实验的精简证据，不复制旧20万步训练，也不重复全部5600条轨迹。

| 位置 | 内容与用途 |
|---|---|
| `PPO正式模型/nominal` | 普通PPO，种子11、22、33 |
| `PPO正式模型/randomized` | 随机化PPO，种子11、22、33 |
| 每模型的`best_model.zip` | 验证集选中的策略，未重训或修改权重 |
| 每模型的`training_metadata.json`与`training_manifest.json` | 预算、物理条件、网络、依赖版本与训练来源 |
| 每模型的`validation_history.csv`、`best_checkpoint.json`和`validation_scenarios.json` | 选模记录及验证场景 |
| 每模型的`monitor_0.monitor.csv` | 环境0训练奖励日志，对应外层训练图的上半幅 |
| [episode_metrics.csv](统计与场景/episode_metrics.csv) | 全部5600回合指标，不只保留最好模型 |
| [summary.csv](统计与场景/summary.csv) | 按16个工况分别汇总 |
| [family_summary.json](统计与场景/family_summary.json) | 外层六类工况表的直接来源 |
| [test_scenarios.json](统计与场景/test_scenarios.json) | 800场景完整配置 |
| [evaluation_manifest.json](统计与场景/evaluation_manifest.json) | 控制器、样本量及PID参数来源 |
| [result_verification.json](统计与场景/result_verification.json) | 既有正式结果全量核验，状态passed |
| [figure_manifest.json](统计与场景/figure_manifest.json) | 图的固定示例选择原则 |

`固定配对轨迹`仅保留`test_00_001`的PID、普通PPO seed 11、随机化PPO seed 11三条`.npz`。它们对应外层配对图，是固定演示，不代表统计平均或每个种子表现。完整指标CSV中的其他`trace_file`路径属于源成果包，答辩包没有复制这些全部轨迹；不要把未打包的轨迹误判成已打包文件。

本阶段代码复用包内[第二步完整V1模块](../../02_单轴建模与PID基线/支撑代码与数据/代码/satellite_benchmark)，其中`training.py`负责训练和选模、`env.py`负责随机化与奖励、`evaluation.py`负责配对测试、`plotting.py`负责图表。

这是代码阅读与证据包，当前没有新训练或重新计算全量测试。模型原元信息保留训练时的绝对路径及文件名，例如`final_model.zip`；为精简只复制选中`best_model.zip`，所以元信息中提到的其他检查点不表示也已打包。所有原样副本，包括外层三张图，见[来源清单](来源清单.json)。
