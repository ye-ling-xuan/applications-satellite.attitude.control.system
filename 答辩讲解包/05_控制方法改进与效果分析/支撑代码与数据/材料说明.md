# 第05步支撑材料怎么用

本步支持两条结论：PID整定／滤波的对照，以及同一学习模型的零动作校准。所有CSV、配置和关键代码都是已有文件的原样副本；[来源清单](来源清单.json)给出来源及SHA256。

| 材料 | 你可以核对什么 |
|---|---|
| [PID参数](参数与验证/pid_configs.json) | 实际入选Kp、Ki、Kd、alpha；单轴alpha=1，整定／改进Ki=0 |
| [单轴搜索](参数与验证/pid_search_single.csv)、[三轴搜索](参数与验证/pid_search_three.csv) | 所有验证候选，不只保留最好一组；不同搜索预算公开 |
| [PID逐场景配对](结果数据/paired_improvements.csv) | 改进相对原始／整定基线的误差、成功率和控制代价变化 |
| [校准规则清单](参数与验证/policy_calibration_manifest.json)、[验证记录](参数与验证/policy_calibration_validation.csv) | 不改网络权重、不用真实状态，正式测试前保留全部原／校准版本 |
| [校准逐回合配对](结果数据/policy_calibration_pairs.csv) | 3240个同轴、同算法、同种子、同场景配对；挽回和失去的成功 |
| [完整逐回合结果](结果数据/episode_metrics.csv) | PID与原／校准RL都在；没有只保留表现好的版本 |
| [控制器代码](关键代码/controllers.py)、[校准代码](关键代码/improvements.py)、[指标代码](关键代码/metrics.py) | 增益、角速度滤波、条件积分、校准公式和验收定义 |

从本目录运行下面命令，可只用Python标准库复算四组PID改进统计和六组RL校准统计，不加载模型、不训练、不写文件：

```powershell
python .\复算改进配对.py
```

完整模块依赖和18组模型索引位于上一研究步骤的[代码目录说明](../../04_三轴扩展与多算法公平比较/支撑代码与数据/材料说明.md)，其中复制了4份代表best模型；此处不重复大模型。当前三份关键代码副本用于逐行阅读，单独放在此目录并不是独立可导入的完整Python包。

`代表轨迹`含四条原样NPZ：三轴SAC(seed_11)在nominal_000的原／校准一对，以及三轴整定／改进PID在combined_000的一对。这些场景用于说明如何找到同场景证据，不代表全部测试，也不是“挑出最好曲线来证明优势”。完整定量结论来自全量CSV。源CSV中的trace_file指向原成果包历史轨迹结构，本包未复制全部raw轨迹，也未修改这些路径。

本步对照不具有以下含义：没有证明单个PID模块贡献了全部提升；没有发明新的SAC训练算法；没有完成在轨验证或电能测量；没有证明SAC普遍最优。原成果包中第08步的惯量研究是后续独立实验，应在下一研究步骤解释。
