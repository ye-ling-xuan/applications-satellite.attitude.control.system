# 运行与复核说明

直接打开`按顺序阅读.html`或`论文正文初稿.html`即可离线阅读，阅读不需要Python。Markdown文件用于编辑，在VS Code中按`Ctrl+Shift+V`预览；独立公式使用独占行的`$$`分隔符，编辑区显示LaTeX源码属于正常情况。

## 核验当前包

在项目根目录使用已验证的Anaconda解释器：

```powershell
& 'D:\Anaconda2024.06-1\python.exe' -X utf8 -B '答辩讲解包/核验讲解包.py'
```

增加`--check-originals`会按原封存清单重新哈希原交付文件。核验脚本检查8步结构、所有登记原件与副本的指纹、讲解材料链接、离线公式，以及新增27组轨迹的真值验收与完整时域力矩代价；读取已完成的独立物理核验记录。本脚本不训练、不选模、不重调参，也不声称重新执行了独立物理核验。

`--seal`仅供新版本首次封存，已有清单时拒绝覆盖。当前脚本核验“公式显示修正版”，原“柔性附件论文版”的清单和核验结果保留为历史记录。需要修改正文时应编制新的版本清单，不能覆盖已有封存记录冒充未改动。

## 重建阅读页

```powershell
& 'D:\Anaconda2024.06-1\python.exe' -X utf8 -B '答辩讲解包/生成阅读本.py'
```

构建依赖`markdown`和`latex2mathml==3.78.1`。本机后者已安装于忽略目录`工作区临时/文档渲染依赖`；换电脑可安装这两项。脚本同时生成八步阅读页和论文正文阅读页，构建出的HTML自带原生MathML，不需要联网或浏览器插件。

## 新柔性实验原工程

完整代码位于`结项成果包/16_柔性附体振动抑制连续控制/07_训练修正与复核/10_补充实验与论文复核`。其`实验执行说明.md`记录执行顺序，`01_方案与冻结`记录测试前冻结，`02_新独立测试`保留所有响应，`03_独立核验`与`04_统计`保留全量物理和配对统计结果。

新测试未增加训练模型。三个正式模型仍为第06步指向的`best.zip`；正式训练各1,048,576步，选用验证检查点分别262,144、393,216、327,680步。测试时参数固定。

大型模型与轨迹用来源路径引用，并未全部复制入本讲解包。分发用于完整复核时须保留项目相对目录；浏览器视觉检查的临时配置应留在`tmp`或`工作区临时`，两者已被Git忽略，避免再次推送浏览器缓存。
