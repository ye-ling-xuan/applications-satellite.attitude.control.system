# 阅读、代码与数据怎样配合使用

## 先阅读，再查证据

每一步的`本步讲解.md`给出研究逻辑和读图说明，`答辩与论文用稿.md`给出可编辑口述与段落。外层图表帮助讲解；内层`支撑代码与数据`保存原样代码、参数、关键完整表格和精选轨迹。`来源清单.json`记录每个副本来自哪里以及SHA256，用于核对是否复制完整。

CSV是逐回合记录或统计表，JSON是配置、元信息或核验记录，NPZ是保存的数组轨迹，模型ZIP是训练权重与算法状态。模型ZIP不是压缩版研究报告，双击也不能直接看到控制曲线。

本包保留完整关键结果CSV，因此总体成功率与主要对比能在本包内复算。只选入少量原始轨迹用于解释具体成功或失败；全部轨迹与完整原始工程继续在原成果包，不能从精选几条曲线推断全体结果。

## 最简单的只读核对

在“答辩讲解包”目录运行：

```powershell
python -B 核验讲解包.py
```

本机已验证的解释器也可以这样用：

```powershell
& 'D:\Anaconda2024.06-1\python.exe' -X utf8 -B 核验讲解包.py
```

它使用Python标准库，检查讲解包文件哈希、本地讲解链接与副本清单，并从V1/V2/V3的完整逐回合CSV重新计算核心成功率和V3域外代价差。输出到终端，默认不写文件、不训练、不重新选模型、不改任何原数据。

若讲解包与原成果仍在本项目中，可加`--check-originals`检查原副本来源及原交付清单绑定文件：

```powershell
python -B 核验讲解包.py --check-originals
```

这个选项还会读取原V3技术冻结清单覆盖的完整文件，数据约1GB，耗时会比只核对讲解包长。它只读原件；不会刷新旧成果包的任何核验记录。

## 原样代码怎样看

先找到本步讲解中对应的函数。环境代码解释“卫星下一刻怎么动”，控制器代码解释“如何决定力矩”，训练代码解释“如何学习”，评价代码解释“如何判断成功”。先理解这四种职责，再阅读训练入口。

代码按来源原样保留，相关模块与原路径可在该步的来源清单中查到。模块跨文件调用、模型加载版本等依赖也要满足；具体保存布局和运行目录以各步骤的支撑说明为准。查看代码不需要重新训练。

正式实验的完整复现仍以原`结项成果包/README.md`和各版本入口为准，模型推理需要其`requirements-tested.txt`所列的已验证环境。完整复现使用新的输出目录，避免覆盖保存证据。本包的默认核对命令只重算现成表格，不执行那些实验入口。

## 阅读本与核验材料

[按顺序阅读.html](按顺序阅读.html)把七步讲解合成一个离线阅读入口，保留图片、表格和到支撑材料的链接；用浏览器打开即可，无需联网。[讲解包清单](讲解包清单.json)绑定本包正式文件；[本次核验结果](核验结果.json)记录交付时的实际检查。后者不纳入自己的哈希清单，以免形成循环。

如需更新阅读HTML，可运行`python -B 生成阅读本.py`，该生成动作需要`markdown`包，只输出本包的阅读HTML。正式文件变更后，旧哈希清单会如实报不一致，需要审核新版本；不应通过跳过核验来掩盖修改。
