# 本步支撑材料怎么读

本步用于确认研究对象与完成范围，没有新增实验。

| 副本 | 用途 |
|---|---|
| [项目成果.md](范围与标准/项目成果.md) | 学校附件3成果栏的内容稿，确认本次交付边界 |
| [实验设计与验收标准.md](范围与标准/实验设计与验收标准.md) | 第一版单轴的建模和比较规则，保留其历史阶段表述 |

| [V2_result_summary.json](阶段完成证据/V2_result_summary.json) | 第二版单轴/三轴多算法融合的结果清单 |
| [V3_training_batch_summary.json](阶段完成证据/V3_training_batch_summary.json) | 第三版12份SAC正式训练的归档 |

V1标准中“尚未完成三轴强化学习”属于该阶段的历史状态，后续三轴学习结果在第04步。JSON内的原始绝对路径按原样保留，不代表答辩包要求安装到同一硬盘位置。三阶段环境和协议不同，各自结果分别解释。

所有副本已在[来源清单](来源清单.json)登记。这里没有使用原“大创报名材料”的计划内容。
